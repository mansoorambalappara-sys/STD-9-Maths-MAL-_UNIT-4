തുകകളുടെ ഗുണനം

രണ്ട് തുകകൾ തമ്മിൽ ഗുണിക്കുമ്പോൾ, ആദ്യത്തെ തുകയിലെ ഓരോ സംഖ്യയേയും രണ്ടാമത്തെ തുകയിലെ ഓരോ സംഖ്യകൊണ്ടും ഗുണിച്ച് ഗുണനഫലങ്ങൾ കൂട്ടണം.

$(x+y)(u+v) = xu + xv + yu + yv$
ഉദാഹരണത്തിന്: $26 \times 15 = (20+6) \times (10+5) = 200 + 100 + 60 + 30 = 390$.

വ്യത്യാസ ഗുണനം

രണ്ട് വ്യത്യാസങ്ങൾ തമ്മിൽ ഗുണിക്കുന്നതിനുള്ള ബീജഗണിത സമവാക്യം:

$(x-y)(u-v) = xu - xv - yu + yv$
ഇത് വലിയ സംഖ്യകളിൽ നിന്ന് ചെറിയ സംഖ്യകൾ കുറച്ച് ഗുണനം എളുപ്പമാക്കാൻ സഹായിക്കുന്നു.

തുകയും വ്യത്യാസവും

ഒരു തുകയും മറ്റൊരു വ്യത്യാസവും തമ്മിലുള്ള ഗുണനം:

$(x+y)(u-v) = xu - xv + yu - yv$
ഇത് മാനസിക കണക്കുകൂട്ടലുകൾക്കും വലിയ സംഖ്യകളുടെ ഗുണനത്തിനും വളരെ ഉപയോഗപ്രദമാണ്.

അടുത്തടുത്ത സംഖ്യകളുടെ ഗുണനം

തൊട്ടടുത്ത എണ്ണൽസംഖ്യകളുടെ ഗുണനഫലം കണ്ടെത്താനും സർവസമവാക്യങ്ങൾ സഹായിക്കുന്നു.

$(x+1)(y+1) = xy + x + y + 1$
തൊട്ടുപുറകിലുള്ള സംഖ്യകളുടെ ഗുണനം: $(x-1)(y-1) = xy - (x+y) + 1$.

കലണ്ടർ & ഗണിത മാതൃകകൾ

കലണ്ടറിലെ സമചതുരങ്ങളിൽ വരുന്ന നാല് സംഖ്യകളുടെ കോണോടുകോൺ ഗുണനഫലങ്ങളുടെ വ്യത്യാസം എപ്പോഴും 7 ആണ്.

ഇത് ബീജഗണിത സമവാക്യങ്ങൾ ഉപയോഗിച്ച് എളുപ്പത്തിൽ തെളിയിക്കാം ($x(x+8) - (x+1)(x+7) = 7$).

ക്രിയാകൗതുകങ്ങൾ

രണ്ട് രണ്ടക്ക സംഖ്യകളുടെ ഗുണനഫലവും അവയുടെ അക്കങ്ങൾ തിരിച്ചിട്ട കിട്ടുന്ന സംഖ്യകളുടെ ഗുണനഫലവും ഒന്നുതന്നെയാകാനുള്ള ഉപാധി ആദ്യത്തെ അക്കങ്ങളുടെ ഗുണനഫലവും രണ്ടാമത്തെ അക്കങ്ങളുടെ ഗുണനഫലവും തുല്യമാവുക എന്നതാണ് ($mp = nq$).

ഉദാഹരണത്തിന്: $32 \times 46 = 1472$ ഉം $23 \times 64 = 1472$ ഉം ആണ്.
